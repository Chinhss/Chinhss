# Hi, I'm Chinh

Second-year Computer Science student at Dublin City University and lab tutor for about 200 first-year students. I like building things that run locally, measuring them, and explaining how they work.

## Featured projects

**[Local AI CLI](https://github.com/Chinhss/Local-AI-project)** (Python, Ollama)
A command-line assistant running a 30B-parameter model on a laptop GPU: 33 tokens/s and 2.1 s to first token (medians of 9 runs). Streaming, persistent history, slash commands, and a sandboxed file tool with tests.

**[Lunar Landing Site Navigator](https://github.com/eugeniobusta/lunar-navigator)** (TypeScript, React) · NASA Space Apps, HackAthlone 2026
Team of 6. I specified the Window Finder, which picks the best landing hour for every day of a lunar mission in O(1) per candidate (prefix sums and a sparse table), checked against brute force. I also designed the website. [Live demo](https://claudes-plan-lunar-navigator.vercel.app)

**HeisenCoffee** (Node.js, Express, MongoDB): coffee shop ordering platform, customer-side menu and cart plus backend setup.
